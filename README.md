# Tic Tac Toe

A simple two-player Tic Tac Toe game for the console, written in Python.
Built to practise Git and GitHub: branching, merging and resolving conflicts.

## How to run

    python tic_tac_toe.py

## How to play

Players take turns choosing a square from 1 to 9. The first player to get
three marks in a row, column or diagonal wins.
